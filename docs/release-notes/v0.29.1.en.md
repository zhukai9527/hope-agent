# Hope Agent 0.29.1 — Safer Server Access and Better Skill Management

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.29.1/docs/release-notes/v0.29.1.md) · **English**

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.29.1/CHANGELOG.md) for details.

Hope Agent 0.29.1 brings a more complete skill management experience, tighter security for remote server access, and clearer Docker deployment diagnostics. Skills are now easier to discover, install, migrate, and publish.

## Highlights

- **A complete skill management experience**: The Settings page now includes skill statistics, search, source and status filters, sorting, detailed metadata, and manual rescanning.
- **Safer skill package migration**: Import skill ZIP packages with a preflight check, protection against accidental overwrites, and export individual skills for easier transfer between environments.
- **Skill marketplace and cross-app installation**: Browse ClawHub-compatible markets, discover and safely update skills from local directories, and install them into Claude, Codex, Gemini, and OpenCode skill directories.
- **A complete publishing workflow**: Configure Market Hub sources, manage authorization per source, create publishing drafts, and explicitly confirm before pushing local skills to an authorized SkillHub/ClawHub-compatible marketplace.

## Security and Deployment

- **Safer remote server access**: Browser login now uses an HttpOnly session, while remote WebSocket and file preview access use short-lived, restricted credentials. The current page automatically reconnects after a server token is saved or rotated.
- **Clearer Docker sandbox diagnostics**: Container deployments can detect a mounted Docker daemon even when the Docker CLI is unavailable and report missing or insufficient permissions clearly. The isolated mode is supported, while unsafe modes are rejected.
