# Hope Agent 0.29.1 — 技能管理与服务端安全升级

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.29.1/docs/release-notes/v0.29.1.en.md)

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.29.1/CHANGELOG.md)。

v0.29.1 带来更完整的技能管理体验，并进一步收紧服务端远程访问安全；同时改进 Docker 部署诊断，让技能从发现、安装到发布更加顺畅。

## 亮点

- **技能管理更完整**：设置页新增技能统计、搜索、来源与状态筛选、排序、详情信息和手动重新扫描，管理内置与本地技能更清晰。
- **技能包可安全迁移**：支持对技能 ZIP 包进行导入前检查、拒绝意外覆盖，并可导出单个技能，方便在不同环境间迁移。
- **技能市场与跨应用安装**：可浏览 ClawHub-compatible 市场，从本地目录发现并安全更新技能，并安装到 Claude、Codex、Gemini 和 OpenCode 的技能目录。
- **技能发布闭环**：设置页新增 Market Hub、按来源管理授权、发布草稿与推送入口，可将本地技能明确确认后发布到已授权的 SkillHub/ClawHub-compatible 市场。

## 安全与部署

- **远程服务访问更安全**：浏览器登录使用 HttpOnly 会话，远程 WebSocket 与文件预览使用短时受限凭据；保存或轮换服务端 Token 后，当前页面会自动续接。
- **Docker 沙箱诊断更清晰**：即使容器内没有 Docker CLI，也能识别已挂载的 Docker daemon 并报告缺失或权限问题；容器部署支持受限的 isolated 模式，其他不安全模式会被拒绝。
